# Pulse — установщик для Windows

Здесь лежат только готовые сборки приложения Pulse для нашей группы. Исходный код — в приватном репозитории.

## Как установить

1. Открой [последний релиз](../../releases/latest) и скачай `Pulse-Setup-<версия>.exe`.
2. Запусти его. Установщик пока без цифровой подписи, поэтому Windows может показать «Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае». Права администратора не нужны.
3. **Регистрация:** «Регистрация по инвайту» → код инвайта от администратора (одноразовый, 24 часа) → ник и пароль от 10 символов.
4. **Секрет группы:** администратор передаёт его отдельно от инвайта — лично или через Signal. Введи его точно: без него чат не читается и голос не подключается.
5. Что-то не работает — «Настройки» → «Диагностика» → «Скопировать диагностику» и отправь текст администратору. В отчёте нет паролей, ключей и сообщений.

Нужна Windows 10 или 11 (64-бит). Автообновления пока нет: новую версию нужно скачать отсюда и установить поверх.
